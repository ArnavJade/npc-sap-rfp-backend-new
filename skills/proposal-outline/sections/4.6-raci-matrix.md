# 4.6 RACI Matrix (intro before `{{table:raci}}`)

Briefly introduce the RACI responsibility model in 2-3 sentences before the matrix that follows.
Do not list the roles or activities yourself; the matrix does that.

The renderer appends the standard matrix with its legend:
- rows: the cross-cutting SAP Activate delivery activities, from Project Planning & Governance to
  Hypercare / Post Go-Live Support;
- columns: Client Sponsor, Client SME / Core Team, YASH Project Manager, YASH Solution Architect,
  YASH Consultants.
The full convention is in the proposal-writing skill, `reference/visuals.md`. Modules are not
rows; per-module scope lives in Functional Scope.

Use the 2-3 sentences to say how accountability is shared between the client and YASH, with
exactly one Accountable party per activity. Point out where the client's own team carries
Responsible roles: requirements workshops, data migration, UAT, and training and change. If the
RFP prescribes a responsibility model or roles (`excerpts:4.6`), echo it.
